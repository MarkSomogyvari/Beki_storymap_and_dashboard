# General idea

We are developing a storymap for the beki river catchment. The storymap will consist of multiple numbered points of interest, which we should be able to scroll down continuously, but also navigate by clicking on the markers.



In a later stage, we would like to add some additional overlay maps to the visualization, via an extra button and a timeline slider. This should be developed using placeholder data - placeholder tiff files. This is the dashboard part of the system
